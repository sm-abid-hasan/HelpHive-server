# HelpHive Server

**HelpHive Server** is the REST API for HelpHive, a community-driven event management platform. It is built with Express.js and MongoDB and provides endpoints for discovering community events, creating and managing events, and joining or leaving activities.

The API is designed to work with the separate HelpHive Next.js frontend. Protected endpoints verify JSON Web Tokens (JWTs) issued by the frontend's Better Auth installation.


## Technologies Used

- Node.js
- Express 4
- MongoDB 
- MongoDB Atlas
- jose


## Features

1. **Upcoming Event Listing**
2. **Event Details** 
3. **Event Creation**
4. **Event Management** 
5. **Event Participation** 
6. **Joined Event History**
7. **Duplicate Join Protection** 
8. **JWT-Protected API** 
9. **Request Validation** 
10. **Centralised Error Handling**
